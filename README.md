# mparvan.github.io

Personal academic and professional website for Milad Parvan.

The site is hosted with GitHub Pages and built with Jekyll. It presents selected research projects, publications, professional experience, and contact information.

## Main sections

- Home
- Research
- Publications
- CV
- Contact

## Development

The site uses the AcademicPages / Minimal Mistakes Jekyll structure inherited from the original repository. Content is maintained primarily through Markdown and YAML files.

GitHub Pages performs the production build after changes are merged into the publishing branch.
